5. Android - foreground-service default text

PREVIEW - strings from utils/geo.js (backgroundTitle / backgroundMessage)

Run Conquest
Run in progress
Tracking your territory run - tap to return.

The background-geolocation plugin posts this first (id 28351); RunNotificationPlugin replaces it with the stats card above once the watcher is up. It is what shows if the custom view ever fails to take over.

6. Android - run finished / saved

PREVIEW - nothing is shown (not implemented)

No notification. stop() cancels notification 28351 and nothing replaces it; the result is only the in-app Run Rewards modal. No "run saved" / "territory claimed" notification exists.

8. Broadcast / news

PREVIEW - no OS notification exists

Not in the notification bar. Broadcasts arrive over the STOMP socket (/all/mail) while the app is open, or by fetch when it opens / returns to the foreground. They show as the in-app Announcement popup (important notices), the unread badge and the News tab - see broadcast-*.png.

9. iOS - run in progress

PREVIEW - nothing custom is built

No lock-screen stats. RunNotification is Android-only. On iOS the only indicator is the system's blue location pill / status-bar indicator while tracking in the background (showsBackgroundLocationIndicator). Live Activity is in the proposals table.
